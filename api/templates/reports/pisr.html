How to read this report
  • Every figure was read once, at generation time. A client count or a radio channel is a snapshot, not a trend.
  • A skipped check is one that could not run — usually because the thing it tests is absent — and is not a pass.
  • Subnet prefixes marked inferred or assumed are derived, not read from the device. Only reported comes from a device's own netmask.
  • PISR reads only. It changes nothing in RUCKUS ONE, and stores nothing after the report is delivered.
